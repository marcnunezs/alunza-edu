# Componentes de interfaz

Button, Input y Card se adaptaron del registro oficial **shadcn/ui, new-york-v4** consultado el 10/09/2026:

- https://ui.shadcn.com/r/styles/new-york-v4/button.json
- https://ui.shadcn.com/r/styles/new-york-v4/input.json
- https://ui.shadcn.com/r/styles/new-york-v4/card.json

Se copiaron manualmente las fuentes inspeccionadas para no ejecutar un generador que reescribiera el workspace. Las adaptaciones limitan variantes al consumidor actual, elevan controles a 44–48 px, usan encabezados semánticos y resuelven `cn` localmente. El registro remoto no está versionado; las fuentes vendorizadas y el lockfile del repositorio constituyen el artefacto reproducible.
